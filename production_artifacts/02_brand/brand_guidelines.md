# Production Artifact: 02_brand / Brand Guidelines

## Color Tokens & Swatches
| Token Name | Hex Code | Purpose |
| :--- | :--- | :--- |
| `bg-primary` | `#060608` | Canvas & atmospheric background |
| `bg-card` | `rgba(18, 18, 22, 0.75)` | Glassmorphic floating surfaces |
| `accent-gold` | `#D4AF37` | 24K liquid gold typography & borders |
| `accent-gold-light` | `#F3E5AB` | Glowing highlights & focus states |
| `text-primary` | `#F4F1EA` | Alabaster white primary headlines |
| `text-secondary` | `#A09F9C` | Refined subtitle & meta text |

## Typography Scale
- **Headlines**: `Playfair Display` (Serif, italic elegance)
- **Badges / Monograms**: `Cinzel` (Classical Roman proportions)
- **Body / Telemetry**: `Plus Jakarta Sans` / `Montserrat` (Clean geometric readability)
