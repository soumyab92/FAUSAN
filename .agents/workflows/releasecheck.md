# Workflow: Release Checklist (`/releasecheck`)

## 🎯 Purpose
Run final pre-deployment audit to ensure production readiness.

## 📋 Steps
1. Run syntax validation across all scripts.
2. Confirm zero console errors in browser runtime.
3. Validate all internal navigation anchor links (`#chapter-silhouette`, `#chapter-collection`, etc.).
4. Verify standalone bundle integrity in `app/`.
