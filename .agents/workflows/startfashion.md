# Workflow: Start Fashion Platform (`/startfashion`)

## 🎯 Purpose
Initialize the local development environment, verify video assets, and launch the HTTP server.

## 📋 Steps
1. Verify `Full_body_front_facing_camera (1).mp4` exists in `assets/videos/`.
2. Start the local server:
   ```bash
   node server.js
   ```
3. Confirm `http://localhost:3000/` returns HTTP 200 OK.
