# Skill: Project Management

## 🎯 Goal
Provide guidance for planning, tracking, and executing fashion-commerce platform deliverables with zero technical debt.

## 📋 Best Practices
1. **Milestone Scoping**: Break all features into atomic, verifiable phases (Charter, UI System, 3D Kinematics, QA).
2. **Strict Verification**: Every code modification must be verified on live browser runtime (`http://localhost:3000/`) before sign-off.
3. **Change Logging**: Log all architectural deviations into `docs/Decision_Log.md`.
